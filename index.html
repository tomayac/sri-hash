SRI Hash Generator

Generates Subresource Integrity hashes. Every result has its own bookmarkable URL.

Source

The path only fills in the HTML snippet. A path ending in .css gives you a <link> tag.

Hash algorithms
URL format

Link to ?url=resource&algorithm=sha256. Repeat algorithm or separate values with commas to get several hashes, for example algorithm=sha384,sha512. Without an algorithm, SHA-384 is used.

Hashing happens in your browser, so the resource must be served with an Access-Control-Allow-Origin header. Cross-origin SRI needs that header anyway.

Links to pasted code keep the code in the fragment after #, which browsers never send to a server. Short code is stored compressed. Code that compresses to more than 600 characters is stored as its hashes only, so the link stays at about 200 characters.

Pasted code is hashed as UTF-8 with LF line endings. The file you serve must match it byte for byte, including whether it ends with a newline.
